# GALAXY DRIFT: OVERDRIVE

高速スクロール宇宙アクション。スマホ・PC両対応のブラウザゲーム。

## Play
- **PC**: マウスで操縦 / `Space` または クリックでスローモーション
- **モバイル (タッチ)**: 画面をドラッグして機体を操作 / 中央のSLOWボタンで時間減速
- **モバイル (傾き)**: 端末を傾けて操縦（許可が必要）

## Features
- エネルギーコア(黄)でコンボ加算、シールド(青)で無敵、マグネット(桃)でアイテム吸引、スロー(紫)でピンチ回避
- 障害物パターン: 直進 / サイン波 / ホーミング / クラスター
- グレイズ判定でニアミスがスコア化
- ハイスコア自動保存 (localStorage)

## Run locally
```bash
python3 -m http.server 8000
# open http://localhost:8000
```
