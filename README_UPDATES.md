# GALAXY DRIFT: OVERDRIVE v3 - 改善内容

## 🎮 ゲーム性の向上

### 新アイテム追加
- **ボム (Bomb)**: 画面上の岩を一掃する強力なアイテム
  - 5秒間有効で、範囲内の岩を自動破壊
  - 各破壊で150ポイント獲得
  
- **マルチプライヤー (Multiplier)**: スコア倍率アップ
  - 8秒間、全スコアが2倍になる
  - 視覚的なインジケーター付き

### レベルシステム
- 進行時間に応じてレベルが自動上昇
- 画面右上にリアルタイム表示

## 🎯 難易度調整

### 岩の生成頻度を最適化
- **序盤**: 岩の生成を削減（0.045 → 0.02）
- **中盤以降**: 段階的に難易度上昇
- **スピードスケーリング**: より緩やかな上昇曲線

**効果**: 初心者でも楽しめる難易度バランスに改善

## 🎛️ ジャイロ操作の強化

### 感度向上
- 傾き判定を18°から15°に変更（より敏感に反応）
- ジャイロ感度を1.2倍にブースト
- 機体の傾き表現を追加（視覚的フィードバック）

### 改善点
- より直感的で反応性の高い操作感
- 機体が傾きに応じて視覚的に回転

## 🎨 ビジュアル改善

- マルチプライヤー状態の表示
- ボムアイテムの専用カラー（オレンジ）
- 各アイテムの脈動アニメーション強化

## 📊 スコアシステム

- マルチプライヤー適用時のスコア計算を全体に統一
- グレイズボーナスにもマルチプライヤーを適用
- コンボボーナスの計算式を最適化

## 🔊 サウンド

- ボム効果音追加
